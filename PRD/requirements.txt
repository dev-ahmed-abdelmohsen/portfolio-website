1. Project Overview
Create a highly optimized, responsive personal portfolio website for a DevOps, Software, and Cloud Engineer. The application must utilize an "App Shell" architecture, separating fixed navigation/profile components from a central dynamic content container that updates on route changes.

2. Tech Stack & Configuration
Framework: Next.js 15 (App Router).

Language: TypeScript (Strict mode enabled).

Styling: Tailwind CSS (Dark mode by default, utilizing a geometric polygon background pattern).

UI Components: Shadcn UI (for buttons, cards, badges, and form elements).

Icons: Lucide React.

Animations: Framer Motion (for smooth fade-in page transitions in the dynamic container).

Content: MDX (for the technical blog).

3. Directory Structure Guidelines
Enforce a clean, maintainable architecture within the src/ or root directory:

app/layout.tsx: Houses the App Shell (Global Wrapper, Profile Header, Sidebar, Footer).

app/page.tsx: The About page (default route).

app/(routes)/[name]/page.tsx: Grouped dynamic routes for /resume, /portfolio, /blog, and /contact.

components/layout/: App Shell components (ProfileCard.tsx, Sidebar.tsx, Footer.tsx).

components/ui/: Reusable Shadcn UI components.

lib/: Utility functions (e.g., cn for Tailwind class merging).

data/: Static JSON or TS files containing experience, project, and blog metadata to keep UI components clean.

6. AI Generation Directives
Build the layout skeleton first before populating individual pages.

Default to React Server Components. Use "use client" strictly only when hooks (useState, usePathname for active nav links) or Framer Motion animations are required.

Ensure absolute mobile responsiveness. The side navigation must collapse into a hamburger menu or bottom bar on screens smaller than md.

Keep the code modular. Do not hardcode massive text blocks directly into the page components; map over data arrays where possible.
